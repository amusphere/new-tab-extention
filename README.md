# カスタム新規タブ Chrome エクステンション

新規タブを開いたときにカスタムページを表示するChrome拡張機能です。

## 機能

- 🕐 現在時刻と日付の表示
- 🔍 検索バー（Google検索またはURL入力）
- 🔗 よく使うサイトへのショートカット
- 🎨 美しいグラデーション背景

## インストール方法

1. Chrome ブラウザを開く
2. アドレスバーに `chrome://extensions/` と入力してアクセス
3. 右上の「デベロッパーモード」をオンにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. このプロジェクトのフォルダを選択

## 使い方

- 新しいタブを開くと、自動的にカスタムページが表示されます
- 検索バーに入力して Enter キーを押すと：
  - URL の場合：そのページに移動
  - それ以外：Google で検索
- ショートカットをクリックして、よく使うサイトにすぐアクセス

## カスタマイズ

### ショートカットの変更

`newtab.html` の `.shortcuts-grid` セクションを編集して、お好みのサイトを追加できます。

### デザインの変更

`styles.css` を編集して、色やレイアウトを自由にカスタマイズできます。

## 必要なファイル

- `manifest.json` - 拡張機能の設定ファイル
- `newtab.html` - 新規タブのHTMLページ
- `styles.css` - スタイルシート
- `script.js` - JavaScript コード

## 注意事項

アイコンファイル（icon16.png, icon48.png, icon128.png）は manifest.json で定義されていますが、
無くても拡張機能は動作します。アイコンを追加したい場合は、適切なサイズの画像を用意してください。
